- **변경 내용**:
  - `css/visitor-counter.css`(신규): 네비게이션 바 우측 하단(`top: calc(var(--header-height) + 16px); right: 24px;`)에 고정되는 pill형 `.visitor-counter` 위젯 스타일 작성. 기존 `.hero-badge`/`.stack-item`과 동일한 dark-glass 디자인 언어(반투명 배경, 1px 보더, `border-radius: 50px`) 재사용. 480px 이하 모바일용 축소 스타일 포함
  - `js/visitor-counter.js`(신규): 무가입 무료 카운터 API(`abacus.jasoncameron.dev`)를 이용해 `initVisitorCounter()` 구현. `localStorage`에 마지막 방문 날짜를 저장해 하루 1회만 카운트를 증가(`/hit`)시키고, 같은 날 재방문 시에는 조회만(`/get`) 수행. 오늘 카운터는 `daily-YYYY-MM-DD` 키를 사용해 날짜가 바뀌면 자동으로 0부터 새로 시작하도록 구성, 전체 카운터는 `total` 키로 누적
  - `index.html`: `<head>`에 `css/visitor-counter.css` 링크 추가(`responsive.css` 앞), `</nav>` 바로 아래에 방문자 카운터 마크업(`#visitorCounter`, `#visitorToday`, `#visitorTotal`) 추가, `js/main.js` 앞에 `js/visitor-counter.js` 스크립트 태그 추가
  - `js/main.js`: `initNavbar()`/`initMobileMenu()` 다음 줄에 `initVisitorCounter()` 호출 등록. (기존에 알려드린 `initProjects()` 미정의 버그로 인해 `DOMContentLoaded` 핸들러가 그 지점에서 예외로 중단되는 문제가 있어, 영향을 받지 않도록 그 호출보다 앞쪽에 배치)
- **이유**: 우측 상단에 오늘/전체 방문자 수를 기록·표시해달라는 요청 반영. Playwright로 데스크톱(1280px)·모바일(390px) 뷰포트에서 위젯이 정상 렌더링되고 실제 카운터 API 응답으로 숫자가 채워지는 것을 확인 완료(테스트 중 로컬에서 API를 실제로 호출해 프로덕션 네임스페이스의 카운트가 소폭 증가했음 — 배포 후 실제 방문자 수에 테스트 호출분(오늘/전체 각 2회 내외)이 섞여 들어감)
